# Axiom 3D — Portfolio Website

A clean, professional portfolio website for 3D Product & Industrial Design.
Built with pure HTML, CSS, and JavaScript. No frameworks, no build step — just drop and deploy.

## Deploy to Vercel (3 steps)

1. Go to https://vercel.com and sign up / log in (free)
2. Click "Add New Project" → "Upload" tab → drag this entire folder
3. Click Deploy — your site is live in ~30 seconds

That's it. Vercel will give you a free URL like `your-name.vercel.app`.

## Folder Structure

```
portfolio/
├── vercel.json          ← Vercel deployment config (don't touch)
├── README.md            ← This file
└── public/
    ├── index.html       ← Your main website file
    ├── images/          ← Put your project images here (JPG, PNG, WebP)
    └── models/          ← Optional: put 3D model files here (GLB, OBJ)
```
